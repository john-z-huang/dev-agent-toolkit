# 本地 Serena MCP 工具检查与更新

只有用户明确要求检查或升级本机 uv 安装的 Serena 时，才考虑此流程。普通代码任务、Serena MCP 项目初始化或激活都不构成授权。

当前 dev-agent-toolkit MCP 没有读取 uv 安装来源、检查 Serena 上游版本或升级 Serena 工具的专用能力。可按 [`cli-fallback.md`](cli-fallback.md) 在用户已授权的检查/升级范围内使用 Git、uv 等相关 CLI，无须仅因缺工具再次询问。先核对实际安装入口、版本、安装来源及 editable 路径，不根据旧文档猜安装位置，也不把提交标题兼容脚本当成安装管理器。

如后续版本提供覆盖需求的专用工具，优先使用。源码/editable 安装先核验路径与仓库身份、工作区干净、remote 和默认分支，再只做 fast-forward 更新；其他安装方式先核实原来源与对应 uv 更新方式，不擅自迁移。检查请求仅报告版本/上游状态，不自动升级；执行升级须已有明确授权。更新后核对实际 uv 工具路径、版本和可用性，说明是否还需重载服务；发现来源不明、工作区有改动、分叉或任一阶段失败时停止并保留现场。
