# 项目内容修改

## 进入条件

准备修改代码、配置或开发文档时适用。只读分析不触发实现、暂存或发布。

## 执行条件

用户目标、修改范围和不可改变项明确；准确项目已识别，已有 staged/unstaged/untracked 内容归属已核对。仅修改本任务允许的文件或 hunk，不覆盖、删除、移动或静默恢复无关内容。依赖代码语义的改动同时满足 [代码理解](code-understanding.md)；验证范围由真实变更和项目要求决定。

已有 checkout（包括 detached worktree）原地建分支适用 `create_repository_branch` 的授权及 HEAD 条件，不要求新建 worktree、清空修改或同步别的 checkout。工具区别见 [目录](../references/mcp-tools.md#原地创建工作分支)。

## 离开条件

成功：实际 diff 与目标和授权范围一致，适用验证有真实结果，保留内容完好。暂停：范围、归属或必要事实不清，或出现超出当前授权的新决定；说明影响，不把未实现写成完成。

## 重新进入条件

用户目标、目标项目、允许范围或文件内容变化；只重查受影响事实。
