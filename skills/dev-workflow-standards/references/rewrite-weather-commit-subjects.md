# 历史提交标题重写能力边界

本 Skill 的 MCP 服务不提供旧提交标题转换工具，也不执行 Git 历史改写。用户明确要求此操作时，可按 [`cli-fallback.md`](cli-fallback.md) 使用相关 CLI 或已审阅脚本补足；不因缺少专用工具重复索取已有授权。

历史重写会改变提交 SHA，且可能影响共享分支。先核实精确 refs、提交范围、标题映射、当前工作区和共享状态，以及用户授权覆盖的效果；保留原始 OID 和可恢复引用，先审阅预期映射再执行。完成后回读标题、提交数量、树内容与引用，验证只发生批准的变换。远端更新另需对应授权和保护检查；不自动强推，也不以重写跳过提交规则或实际失败。

`scripts/rewrite_commit_subjects.py` 是通用兼容脚本，不属于 MCP 工具接口。使用前检查实际参数、实现、范围和副作用，按项目 Python 环境运行；脚本不能授予历史改写或远端写入权限。
