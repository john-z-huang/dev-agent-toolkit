# 完成交付与交接

## 进入条件

准备报告任务结果、交接或说明阻塞时适用。

## 执行条件

按用户目标和项目要求核对实际产物与受影响资源。文档核对链接和引用，行为变更运行适用测试。分别报告 PASS、FAIL、SKIPPED 和 BLOCKED。Serena 诊断仅作为辅助证据。

分析任务交付分析结果。合并后如要求清理，按 [Worktree 清理条件](worktree.md#执行条件) 核对。

## 离开条件

完成：目标已满足，适用验证和实际副作用可核对，未验证项和限制明确。交接/暂停：目标未满足时说明已完成内容、剩余工作、证据和最小所需决定，不能宣称完成。

## 重新进入条件

目标、产物或检查结果变化，或获得解除阻塞的新事实。
