# 代码理解

## 进入条件

需要判断控制流、类型、符号引用、调用关系或变更影响。纯文档、日志、精确文本查找和机械修改不强制语义查询。

## 执行条件

按 [代码理解参考](../references/code-understanding.md) 核对 Serena 实际能力、准确项目和语言后端；仅在必要且已授权时初始化。按问题选择最小符号、引用或实现查询，不将文本命中、静态引用或空结果等同运行时关系。多语言子项目与跨包查询以实际构建根和查询覆盖为证据，不因主项目已绑定推定其他模块就绪。

## 离开条件

成功：已有足够且来源明确的证据支撑当前结论。暂停：项目绑定或语义能力不足且普通文件读取不能补齐必要证据；记录具体缺口。降级入口不伪装为语义验证成功。

## 重新进入条件

切换项目/worktree/子模块、源文件或构建配置变化，或结论涉及新的影响范围。
