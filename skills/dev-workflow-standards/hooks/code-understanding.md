# 代码与文档理解

## 进入条件

需要判断代码控制流、类型、符号或变更影响，结构化读取 JSON、YAML、Markdown、TOML 或 HTML，查看已安装第三方包源码，或初始化及核对 Serena 项目配置。日志、精确文本查找和机械修改可直接使用普通文件工具。

## 执行条件

按 [Serena 指令](../references/serena.md) 核对准确项目、语言服务、结构化查询及降级条件。首次配置和已有配置补齐按当前授权执行。按问题限定文件或符号范围，独立项目和依赖目录分别核对所用工作区。涉及历史会话事实时先按 [代码理解参考](../references/code-understanding.md) 核对来源。

## 离开条件

证据充分时记录查询方式和证据范围。项目绑定或语义能力不足且普通文件读取无法补齐证据时，暂停受影响的判断并记录缺口。

## 重新进入条件

切换项目、worktree、子模块或依赖目录，源文件或配置变化，或结论涉及新的影响范围。
